# Расстановка текста в чертеже

Как аддин ставит фрагменты текста (обычный, наклонный, индексы) друг за другом и почему.

## Что делает Inventor

Проверено по журналу Inventor 2025 и метрикам шрифта «Gost merged»:

- **Высота текста** в стиле — это высота заглавной буквы. Кегль = высота / 0,684 для «Gost merged».
- **Надпись** (`TextBox`, `AddFitted`):
  - по высоте — по очертаниям букв: у «z» 3,55 мм, у «j» 6,57 мм при высоте 5 мм;
  - по ширине — от левого края букв до конца текста по ширинам букв (как курсор в Word);
  - `Origin` — левый верхний угол.
- **Курсив** у шрифта без своего курсивного начертания Inventor делает наклоном: каждая точка буквы
  сдвигается вправо пропорционально высоте над базовой линией, примерно на 15°. Ширины букв при этом
  не меняются, поэтому верх наклонной буквы выступает правее её ширины, а нижние выносные
  элементы (у, р, д) — левее начала.
- **Растяжение по ширине** (`WidthScale`) стиля примечаний ЕСКД Inventor в размерах надписи
  не учитывает. Стили таблиц «Таблица …» создаются с `WidthScale = 1`.

## Как поступает Word

Word ставит буквы строго по ширинам букв и ничего не делает с наклоном. Поэтому в Word наклонная
буква может налезать на следующую прямую: «*f*)», «*d*|», наклонная буква перед прямой скобкой
или прямым индексом. Решение в Word — вручную добавить пробел или тонкую шпацию.

В TeX для этого есть **поправка на наклон** (italic correction): после наклонного фрагмента
перед прямым добавляется выступ последней буквы.

## Правила аддина

Фрагменты ставятся по ширинам букв из метрик шрифта, как в Word. На стыках — поправка на наклон,
как в TeX:

| Стык | Пример | Поправка |
|---|---|---|
| наклонный → прямой | *D*) , *курсив* прямой | да: выступ последней наклонной буквы |
| прямой → наклонный | D*d* | нет: наклонная буква отклоняется от прямой |
| наклонный → наклонный того же положения (например, жирный) | *ab* | нет |
| наклонный → верхний индекс | *D*² | да: индекс иначе налезает на верх буквы |
| наклонный → нижний индекс | *D*₂ | нет: индекс стоит ниже выступа, как в TeX |
| индекс → основной текст | D²x | по тем же правилам для наклона индекса |

Выравнивание строки по центру и вправо считается по фактическому габариту: от левого края
первой надписи (с учётом нижних выносных элементов наклонных букв) до правого края последней
(с учётом выступа).

## Редактор

Ячейка без курсора показывает **предпросмотр** — текст расставлен тем же кодом, что и в чертеже
(`TextPlanner`): индексы, наклон 15° вокруг базовой линии, поправка на наклон, перенос по словам,
сжатие по ширине. Высоты строк в редакторе — тоже из раскладки чертежа.

Ячейка с курсором показывает поле ввода WPF. В нём индексы и наклон выглядят по-своему (как в Word),
но это только на время набора. Кнопки Ж, К, Ч, x², x₂ показывают формат текста под курсором;
Ctrl+Пробел после индекса возвращает обычный текст, как в Word.

## Строка шире ячейки

Текст переносится по словам. Если строку перенести нельзя (одно слово шире ячейки), она
**сжимается по ширине** ровно настолько, чтобы поместиться между отступами ячейки. Высота букв
не меняется. Сжатие делается коэффициентом ширины стиля текста: для таких строк создаются стили
«Таблица … ш0.62» (коэффициент округляется вниз до сотых). Минимальный коэффициент — 0,1.

В предпросмотре редактора такие строки тоже сжаты; в поле ввода WPF переносит их по буквам.
