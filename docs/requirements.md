# Требования

Редактор таблиц для чертежей Autodesk Inventor 2025. Аддин на C#, .NET 8, интерфейс на WPF. Аддин для личного использования, установщик не нужен.

## 1. Работа с таблицей в чертеже

1. Новая таблица создаётся в окне редактора и вставляется на лист чертежа.
2. При вставке таблица крепится к курсору за **левый верхний угол**. Ставится поверх листа, без привязки к рамке и штампу.
3. Вставленную таблицу можно **перетаскивать мышкой** как единый объект.
4. **Двойной клик** по таблице открывает её в редакторе. После правки таблица перестраивается на том же месте.
5. Кнопки находятся на вкладке ленты **«Пояснения»** (Annotate) в среде чертежа, на своей панели: «Новая таблица» и «Редактировать».

## 2. Окно редактора

Окно **модальное**: пока оно открыто, Inventor заблокирован. Весь функционал собран в одном окне.

### 2.1 Верхняя панель — текст

- Шрифт, размер.
- Жирный, курсив (наклон), подчёркнутый. Классический функционал, как в Word.
- **Надстрочный (x²) и подстрочный (x₂) символ — обязательная функция.**
- Выравнивание по горизонтали: слева, по центру, справа.
- Выравнивание по вертикали: сверху, по центру, снизу.
- Вставка спецсимволов: быстрый список (⌀ ± ° × ≤ ≥ …) и кнопка, открывающая таблицу символов Windows (`charmap.exe`).
- Кнопка общих настроек.

Форматирование применяется к выделенному фрагменту текста. Если ячейка не в режиме редактирования, оно применяется ко всем выделенным ячейкам.

### 2.2 Левая панель — структура (по образцу КОМПАС-3D)

- **Ячейки:** объединить, разделить. Кнопка неактивна, если действие невозможно.
- **Столбец:** выделить, вставить слева, вставить справа, удалить текущий.
- **Строка:** выделить, вставить сверху, вставить снизу, удалить текущую.
- Ширина текущего столбца и высота текущей строки, мм.
- Толщина линий: внешняя рамка и внутренние разделители.

### 2.3 Сетка таблицы

- Текст в ячейках отображается с форматированием, индексы видны сразу.
- Ширину столбцов и высоту строк можно менять перетаскиванием границ.
- Есть контекстное меню и горячие клавиши.
- Флажок «Заголовки столбцов»: включает и выключает строку заголовков.

### 2.4 Текст в ячейке

- Текст переносится по словам по ширине столбца, одинаково в редакторе и в чертеже. Enter — принудительный перенос строки.
- Высота строки таблицы автоматически увеличивается под содержимое.
- Выравнивание по умолчанию: заголовки по центру, данные по левому краю, по вертикали всё по центру.

### 2.5 Буфер обмена

- Копирование и вставка содержимого ячеек в обе стороны с Word и Excel.
- Импорт и экспорт файлов Excel **не нужен**.
- При вставке из Word по возможности сохраняются индексы.

## 3. Шаблоны

- Текущую таблицу можно сохранить как шаблон: структура, размеры, заголовки, содержимое.
- Новую таблицу можно создать из шаблона. Пример: таблица параметров звёздочки.

## 4. Общие настройки

| Параметр | По умолчанию |
|---|---|
| Шрифт | Gost merged |
| Высота шрифта | 5 мм |
| Наклон (курсив) | включён |
| Толщина линий рамки | 0,5 мм |
| Толщина линий разделителей | 0,25 мм |
| Толщина подчёркивания | 0,2 мм |
| Ширина столбца | 20 мм |
| Высота строки | 8 мм (увеличивается, если не помещается шрифт) |
| Отступы текста в ячейке | 1 мм |
| Размер и смещение индексов | подбираются при реализации |

- Кнопка «Сбросить» возвращает заводские значения.
- Настройки пользователя сохраняются в его профиле и применяются к новым таблицам.

## 5. Совместимость

- Чертежи с таблицами открываются, печатаются и экспортируются в PDF и DWG без аддина.
- Шрифт «Gost merged» должен быть установлен на всех компьютерах, где открывают чертёж.
